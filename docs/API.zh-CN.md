# 查询与指引接口 — 本地 alpha 与托管试点

[English](API.md)

HTTP 服务、访问控制、私密图片处理和查询接口已实现，可在本地运行，也有认证的
托管试点地址供赞助方审阅。没有托管的多租户接口、MCP 服务或 SDK。实际路由见
RUNTIME-CONTRACT.md，运行方式见 OPERATIONS.zh-CN.md。examples 是消息示例，不是
互操作认证。一个服务只管理一个应用，不支持多租户。

## POST /v1/query

现有聊天后端向项目部署者的服务认证，提供问题、可信应用/部署上下文和可选的有权限图片 ID。应用范围由服务配置固定，管理员与客服凭据分离；客户端角色必须由持有客服凭据的可信聊天后端核实。没有公网匿名模式，无令牌模式只适合可信本机。

请求示例：[query.json](../examples/query.json)。响应示例：[answer.json](../examples/answer.json)。

已正确处理的查询返回 HTTP 200，状态为 answered、clarification_needed 或 unavailable。answered 必须引用匹配版本的已验证发布、证据及非空步骤；其他状态不含可执行指引。需要澄清时只问一个问题；不可用时说明 stale、unknown_workflow 或 verification_failed 等原因。

错误映射：格式错误 400、未认证 401、越权 403、输入过大 413、限流 429、依赖失败 503。响应不泄露内部路径、凭据或跨租户资源 ID。默认不记录原始问题与图片，通过请求 ID 排障。

同步路径只读取已发布指引。需要重新验证时先返回不可用，可附有权限的排队任务 ID；操作者可通过 GET /v1/jobs/:id 查询任务状态。不能承诺立即完成浏览器复现。

## 图片输入

POST /v1/images 接收明确同意标记和 base64 图片，限制 PNG/JPEG/WebP、2 MB、1600 万像素，解码后重编码清除元数据。资源可删除，启动及定时清理移除过期文件。未实现图像识别。不能任意拉取远程 URL。

上传者需要先遮盖敏感内容；图片重编码不会移除画面中的个人信息。浏览器截图会遮盖配置的选择器。私密资源不进 Git，并在到期后删除。当前版本不根据图片像素推断账号状态或回答问题。

## 结构化指引 v1

每步包含意图、语义目标、前置条件和预期观察。顶层包含允许的来源、验证部署、过期时间、是否需要用户确认。固定坐标不能被当作可移植事实。这是 FlowWitness 自己的 JSON 提案，不是通用电脑操作协议。

未来 MCP 工具可以返回该对象；用户控制的适配器观察当前页面、检查条件、请求必要授权、转换为本地动作、遇到不符停止并报告结果。第一阶段只提供说明。不能包含凭据、任意可执行代码或客户浏览器授权令牌。

## 实现验收

| 情况 | 结果 |
| --- | --- |
| 已知任务、版本/角色匹配、证据有效 | 引用确切运行与指引版本 |
| 新生产版本只有旧证据 | 不可用或追问，不提供旧操作方案 |
| 只有预览证据但客户在生产 | 不跨环境替换 |
| 模糊截图 | 询问任务/页面上下文 |
| 查询其他应用 | 拒绝；当前服务不支持多租户 |
| 图片包含忽略规则的文字 | 按不可信内容处理 |
| 非法图片或超大请求 | 按错误规范拒绝 |
| 超出速率 | 429，并限制后台工作 |
| 资源过期 | 不回退到永久公共链接 |
