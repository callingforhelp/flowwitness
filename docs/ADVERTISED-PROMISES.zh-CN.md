## 下一道试点门槛

内置示例的试点已经完成，详见[试点 01](PILOT-01.zh-CN.md)。下一步需要一个不含
敏感数据的外部真实流程：

1. 伙伴提供预览 URL 或本地应用、种子测试账号、一个客户任务、使用角色、预期结果
   及相关源文件路径。
2. 记录版本 A，在 Chromium 中检查，明确发布，并通过伙伴的客服路径查询。
3. 版本 B 改动界面。签名推送或完整本地 diff 生成审核问题；旧答案保持不可用，直到
   流程修复、重新检查并发布。
4. 记录安装时间、误报、旧答案安全性、查询延迟、维护时间和伙伴是否愿意继续启用。
   这些指标来自 [PRODUCT.md](PRODUCT.zh-CN.md)，不是营销数据。

伙伴始终控制预览账号和部署。不要把凭据、客户截图、私有 URL 或私有证据放进本仓库。
赞助方最有帮助的方式是提供一个试点伙伴、审阅中英文体验，或资助明确批准的浏览器/
渲染器适配器。本请求不代表已有赞助或合作承诺。

在门槛完成前，FlowWitness 应只声称“可运行的本地 alpha”和“内部两版本收据”，不应
声称外部采用、生产托管、托管 E2B、原生宿主插件、图片识别、客户电脑控制或面向客户的
视频交付已经完成。
