# 托管后端检查点

[English](HOSTED-BACKEND.md)

FlowWitness 现在有一个可访问的托管后端，供赞助方审阅和进行无敏感信息试点：

- 接口与操作台：`https://flowwitness-production-5c3588af-7e51-4667-b744-e8542ac0167b.fly.dev/`
- 健康检查：`/health`
- 操作台：`/app/`
- 公共概念边缘预览：`https://flowwitness-preview.dave-z.workers.dev/`

托管服务就是本仓库中的 Node.js/Playwright 应用，使用分离的管理员和客服凭据认证。
服务通过仅项目管理员可调用的 InsForge 表和版本化 RPC，同步工作流状态、任务历史、发布
记录、问题、第一阶段模块记录和私有制品字节。客服模块范围绑定到服务器配置的会话 ID，
客服令牌不能自行选择其他会话。机器重启不会清除试点状态。管理员密钥只注入服务环境，
不会进入仓库或浏览器操作台。

这是托管试点后端，还不是生产认证。目前 InsForge 免费计划只允许一个 512 MB 的
`shared-1x` 机器。HTTP 接口、认证、状态同步、图片上传和制品读取已通过外部检查。
内置 Chromium 可以启动，但在该内存限制下无法稳定创建页面，因此浏览器验证任务在升级
内存或配置获批准的远程浏览器适配器前仍会失败。旧状态和模块记录在 Compute 重启后读取
成功，但没有声称托管浏览器验证成功。

当前试点规格启用了 scale-to-zero。一次冷启动检查超过 15 秒，但在 60 秒内恢复；这只是
试点观察值，还不是客服延迟 SLO。

进入生产还需要：

1. 能通过真实 Chromium 版本 A/版本 B 闭环的更大内存规格，或具备相同来源与证据控制的
   获批准远程浏览器工作进程。
2. 自定义域名/TLS 策略、Webhook 密钥、备份恢复演练、告警，以及由运营方控制的无敏感
   信息预览应用。
3. 重复两版本试点，覆盖当前与过期查询、私密证据访问、中英文响应和重启恢复。
4. 在一个服务承载多个应用前，明确租户隔离和保留策略。

这些检查通过前，应将该地址称为托管试点后端，将 Cloudflare 地址称为公共概念预览。
不要把客户代码或浏览器凭据交给操作台。
