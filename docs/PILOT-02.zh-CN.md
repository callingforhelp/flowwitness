# 试点 02 — 公开路由演练

**日期：** 2026-09-12  
**目的：** 在邀请外部伙伴提供预览目标前，通过公开托管路由执行完整的
Stage 1 发布闭环。

这是赞助方演示演练，不是外部 S1-09 试点。演练使用仓库内置的
`/fixture/` 应用、一次性合成报表数据，以及现有隔离应用命名空间中的新
workflow ID。没有使用客户凭据、个人数据或生产应用。

## 运行环境

- 路由：`https://commodity-consult-hourly-sen.trycloudflare.com`
- 应用命名空间：`demo-reports-ec2-pilot`
- Workflow：`public-pilot-export`
- Checkout：`b7da9c4`（部署的应用代码；后续文档提交不改变运行时代码）
- 计算：与 DSH 共用的现有 ARM64 EC2 主机；FlowWitness 使用回环端口
  4310，DSH 使用回环端口 3080。
- 入口：无账号 Cloudflare quick tunnel。主机名是临时的，不代表生产 TLS
  或可用性承诺。

1. 导入并验证了针对 `fixture-v1` 的新 workflow。
2. 真实 Chromium 在 643 毫秒内回放成功，并生成 15,490 字节的私有 PNG
   （`c4cf612e-b3b5-46f9-92ee-5f8855d08354`）。

4. 支持范围的查询在英文中耗时 249 毫秒、中文中耗时 733 毫秒，均返回
   `answered`。

### 版本 B — `v2`

1. fixture 将**导出报告**移动到**更多**菜单，部署身份变为 `fixture-v2`。
2. 签名 GitHub push 载荷创建了一个审核问题
   （`041bd18f-4fed-4310-b9df-7473e7df643e`）；旧的一步 workflow 回放在
   5,348 毫秒后失败，并保留 12,886 字节的私有失败 PNG
   （`2e15dbdf-8916-4318-8399-83b9cd9d9fc6`）。对失败运行执行发布返回
   HTTP 400。
3. 当前版本查询返回 `unavailable`；显式请求 `v1` 仍返回匹配的旧指南。
4. 修复后的两步 workflow 在 632 毫秒内回放成功，并生成 14,285 字节的

   首步为 `选择更多。`。

   接收具备重放安全性。

## 已检查的边界

- 获得明确同意的图片可通过认证 artifact 路由读取，随后删除；再次使用
  相同 ID 返回 HTTP 404。
- 重启 `flowwitness-pilot.service` 后 DSH 仍为 active，已发布的中文答案
  仍可用（重新连接后 794 毫秒）。
- 公开 API 的未认证访问仍返回 401；公开操作台和 health 端点可访问。
- quick tunnel 不代表固定域名、备份/恢复演练、告警、多应用租户隔离或
  外部采用。

## 决策

现在可以在共用 EC2 主机的公开路由上演示具备浏览器能力的 Stage 1 闭环。
由于本次演练使用 FlowWitness 自己的 fixture，S1-09 仍未完成。下一步外部
动作是获取一个伙伴拥有的、无敏感信息的预览 URL（或本地预览）及部署身份
端点，然后在不改变产品契约的前提下重复这份收据。
