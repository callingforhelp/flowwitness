# Knowledge bank

`createModule({repository, artifacts, jobs, config})` is independent of server, cloud and model clients. `config.now` supplies a fake clock; optional `currentRevision` withdraws old-release eligibility. Public async methods are `create`, `get`, `search`, `publish`, and `feedback`, taking a trusted principal and input. Operators explicitly select a conversation or `conversationId:null`; customers require a bound conversation. Application scope is not a wildcard.

Create concise `report`, `hypothesis`, `observation`, `attempt`, or `resolution` entries with `title`, `summary`, `locale:en|zh`, tags, optional release/role, scoped issue/job/evidence references and `supersedes` IDs. Provenance is server-derived. Agents require their live leased job. Entries start private; status and publication cannot be asserted. Never submit chain of thought, raw deliberation, credentials or browser profiles. Field allowlists are structural protection, not a content redaction service: callers must submit safe summaries.

Search uses Unicode NFKC case-insensitive substring matching over titles, summaries and tags. It preserves original EN/ZH content, sorts by creation time then ID, filters kind/tags/visibility and `context:{release,role,locale}`, and binds cursors to the scope, principal and query. GET query parameters use `locale`, `release`, `role`, comma-separated `tags`, integer `limit`, and boolean-string `includeSuperseded`. No translation is fabricated; get with a different context locale marks `translationMissing`.

Routes: POST/GET `/v1/knowledge`, GET `/v1/knowledge/:id`, POST `/v1/knowledge/:id/publish`, and POST `/v1/knowledge/:id/feedback`. Feedback accepts helpful/unhelpful/outdated/wrong and an optional concise note. Mutations use CAS (`expectedVersion` optional, otherwise the just-read version). Unknown route prefixes return null; unsupported owned methods return 405. Exceptions expose status/code for coordinator serialization.

Only operators publish. Evidence must reference a successful uncancelled scoped job result, trusted validator version, matching release, valid expiry and available non-revoked artifacts with hashes. The repository must protect evidence writes: this module consumes trusted execution records, it does not itself execute or validate browser receipts. Bundle artifact hashes, when present, must match artifact metadata. Failed, expired, stale and unverified evidence blocks publication; every read recomputes eligibility. Customers see only currently verified published entries. Only a currently eligible published successor hides an older entry in default search. Feedback never verifies evidence.

Focused local check: `node --test test/knowledge.test.mjs`. This fixture uses only fake adapters; it is not cloud, authentication integration, or deployed proof. Search scans repository pages for deterministic module filtering; production scale may require an equivalent indexed adapter.
