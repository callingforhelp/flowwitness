For builders · Planned integration

You build the product. Help comes with it.

01

Connect your repo and agent

Your coding agent can use the CLI to record a customer workflow and save its steps alongside your code.

02

Answer in your existing chat

Your support assistant would call a FlowWitness guidance endpoint and return the right steps. Keep your existing chat UI; the endpoint can run locally, self-hosted, or on the hosted pilot.

03

Check again when the UI changes

The service checks affected workflows in a headless browser, flags old instructions, and helps you update them before customers rely on them.

What exists today

A working CLI, browser-checking service and bilingual operator dashboard, plus an authenticated hosted pilot API with durable state. The demo on this page remains simulated; open the hosted UI or install the project to run actual checks.

The next milestones

Stage 1 · Local alpha → real pilots

Use the core loop first: issues, reasoning, agent jobs, workflow checks and clear answers. Next: external pilot workflows, authenticated-app adapters and easier workflow capture.

Stage 2 · Show and assist

Private reproduction and walkthrough-video modules are implemented behind explicit adapters. Customer delivery, image understanding and computer-use execution remain future integrations.

Help test it on your product.

The API and local browser-to-answer loop are real; the hosted pilot is ready for sponsor review. We welcome a pilot partner with one non-sensitive product workflow to test how well it handles real releases.
